Cómo se hace

un comando
01

Tu color

Pasas el hex de tu marca. La paleta deriva cuerpo, luces, sombras y acentos manteniendo la saturación.

02

El rig

Un personaje paramétrico: ojos, cejas, bocas, brazos y props. Cada sticker es una pose sobre el mismo rig, no un dibujo nuevo.

03

QA automático

Se renderiza con rlottie y se verifican formato, frames vacíos, bordes, loop perfecto y peso. Si algo falla, no se publica.

# un pack completo en el color de tu proyecto
python3 scripts/stickers.py --color "#7C3AED"

# o una paleta con nombre
python3 scripts/stickers.py --palette mint

# QA: formato, frames vacíos, bordes, loop, peso
python3 scripts/verify.py
